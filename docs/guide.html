Dualtooth guide

Use the same Bluetooth keyboard, mouse or headphones in Windows and Linux, without pairing them again every time you switch.

What Dualtooth does

When you pair a Bluetooth device, the device and your PC agree on a secret key, like a handshake only they know.

The problem: each device remembers only one handshake per PC. Windows and Linux each make their own when you pair. So whichever system you paired in last works, and the other one doesn't.

The fix: Dualtooth copies the handshake Windows already has into Linux. After that, both systems use the same one, and your devices just work in either.

It takes about 5 minutes: one click in Windows, then one command in Linux. Dualtooth never changes anything on Windows. It only reads.

Before you start

  • Your devices work in Windows right now. If one doesn't, pair it in Windows first (Settings › Bluetooth & devices › Add device).
  • You know your Linux password. You'll type it once. (Forgot it? See I forgot my Linux password.)
  • You have a way to type in Linux the first time. Until Dualtooth's script has run, your Bluetooth keyboard won't work in Linux yet. Use a wired keyboard for this one time, or use your mouse and copy-paste the command.

Part 1: In Windows

  1. Open Dualtooth.exe. Windows asks "Do you want to allow this app to make changes?". Click Yes. Dualtooth needs this to read your Bluetooth pairings; it doesn't change anything. the Dualtooth window, with your devices listed under step 1.
  2. Pick your devices. Each device has a little light. Lit up = it will work in Linux too. Click a device to turn its light on or off. the screen at the top says how many devices will work in Linux.
  3. Check where the script will be saved (step 2 in the app). Your Desktop is the default and is perfect. Leave it unless you have a reason to change it.
  4. Click CREATE LINUX SCRIPT. "SCRIPT CREATED" on the screen, and a checklist under "What's next". A file called dualtooth-apply.sh is now on your Desktop.
  5. Restart into Linux. Use Restart, not Shut down. (Restart lets Linux open your Windows drive; see why.)

Part 2: In Linux

  1. Log in to Linux as usual.
  2. Open your file manager (usually called Files, Dolphin or Nemo).
  3. Open your Windows drive. Look in the left sidebar for something like "1.6 TB Volume", "Windows" or "Local Disk". If you don't see it, click Other Locations. Click it once to open it. It may ask for your Linux password. folders like Program Files, Users and Windows.
  4. Go to Users › your Windows username › Desktop. dualtooth-apply.sh in the list.
  5. Right-click an empty spot in that folder and choose Open in Terminal. a terminal window with a blinking cursor.
  6. Type this exactly, then press Enter: sudo bash dualtooth-apply.sh It asks for your password. Type your Linux password and press Enter. Nothing appears on screen while you type. That's normal. It's still working. one line per device, like Installed Logi K250 (C0:E1:5A:8F:83:AC), then Done.
  7. Turn each device off and back on. each device connects within a few seconds. 🎉 That's it, you're finished.

Afterwards

Delete the script. dualtooth-apply.sh contains your Bluetooth pairing keys. Once your devices work in Linux, delete it from your Desktop and empty the Recycle Bin.
Don't pair these devices again, in Windows or Linux. Pairing again makes a new handshake and breaks the other system. If it happens anyway, no harm done: pair in Windows, then run Dualtooth again.

Something went wrong

I can't open my Windows drive in Linux

Windows has a feature called Fast Startup that leaves the drive "half asleep" when you shut down, and Linux won't touch it in that state.

Fix: go back to Windows and use Restart (not Shut down) to get to Linux. Restart always fully closes the drive.

Permanent fix: in Windows, open Control Panel › Power Options › Choose what the power buttons do, click Change settings that are currently unavailable, untick Turn on fast startup, and save.

Other option: in step 2 of the app, save the script to a USB stick instead, and open it from the stick in Linux.

It says "Bluetooth adapter … was not found"

Nothing was changed. Linux can't see the same Bluetooth radio Windows used. Make sure Bluetooth is turned on in Linux's settings, then run the command again.

If your PC has more than one Bluetooth radio (for example an old USB dongle), open Dualtooth in Windows and use the OTHER RADIO button to pick the one Linux uses.

It says "No such file or directory"

The terminal isn't in the folder with the script. Close it, go back to step 5 of Part 2, and make sure you right-click inside the Desktop folder where you can see dualtooth-apply.sh.

It says "incorrect password" or "Sorry, try again"

That's your Linux password being rejected. Type it slowly. Remember, nothing shows while you type. Check Caps Lock.

I forgot my Linux password

You can set a new one from the boot menu. You'll need a keyboard there.

  1. When the GRUB menu appears, press the ↓ key to stop the countdown. (If it skips straight to Linux, hold Shift or tap Esc while it starts.)
  2. Highlight Linux and press e.
  3. Find the line starting with linux, go to the end of it, and add a space then init=/bin/bash.
  4. Press Ctrl+X. At the # prompt, type these one at a time: mount -o remount,rw / ls /home The name it shows is your username. Then: passwd yourusername Type a new password twice (nothing shows while typing), then: sync reboot -f

If Linux asks for a disk encryption password before the login screen, that's a different password, and this method can't reset it.

It finished, but a device won't connect
  • Turn the device off and on again, then restart Linux once.
  • Was the device lit up in Dualtooth when you made the script? If not, make a new script with it switched on.
  • Did you pair it anywhere after making the script? Then pair it in Windows and run Dualtooth again.
  • Some newer earbuds and phones change their Bluetooth address every few minutes for privacy. Dualtooth doesn't support those yet (see Which devices work).
Windows says "Windows protected your PC" when I open Dualtooth

That's Windows SmartScreen being cautious about a new app it hasn't seen many people use. Click More info, then Run anyway.

My keyboard doesn't work at the Linux login screen

Dualtooth's script turns on a setting that powers Bluetooth up at startup, so this should be fixed after the first run. If it isn't, log in once with your mouse or a wired keyboard and run the script again.

Is it safe?

  • Dualtooth only reads from Windows. It never changes Windows.
  • Your keys go into one file on your own PC and nowhere else. Nothing is uploaded.
  • In Linux, the script backs up anything it replaces (as info.bak) before writing.
