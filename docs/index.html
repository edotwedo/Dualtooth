The Dual-Boot Bluetooth Problem

Why your Bluetooth peripherals refuse to stay connected when switching operating systems.

❌ The Old, Broken Way

  • MAC Address Drift: Pairing in Linux changes the cryptographic link key, breaking Windows connection.
  • Re-pairing Loop: You pair in Windows, boot Linux, re-pair, boot back to Windows, and it's dead again.
  • Manual Hex Editing: Digging into Windows Registry with `psexec -s regedit` and copying raw hex bytes into Linux `/var/lib/bluetooth`.
  • Modern BLE Devices Fail: Bluetooth 5.0 LE (mice, smart pens, modern earbuds) use Identity Resolving Keys (`IRK`) that manual scripts corrupt.

✅ The Dualtooth Way

  • 1-Click Sync: Run Dualtooth on Windows or export to USB. Your Linux pairing keys are updated in seconds.
  • Full BLE 5.0 + IRK Support: Handles `[IdentityResolvingKey]`, `[LocalSignatureKey]`, and Classic `LinkKey` without data loss.
  • BitLocker Safe: Export encrypted keys directly to a USB flash drive without disabling disk encryption.
  • Atomic Non-Destructive: Zero registry risk. Automatic rollback flag (`--undo`) and atomic `.tmp` file commits.

Frequently Asked Questions

Everything you need to know about how Dualtooth works.

Do I have to run Dualtooth every time I reboot?

No. You only run Dualtooth once after pairing a new device. Once the pairing keys are synchronized into Linux's BlueZ database, both operating systems recognize the peripheral permanently on every subsequent boot.

Does Dualtooth work with BitLocker disk encryption?

Yes. If your Windows drive is encrypted with BitLocker, Linux cannot read the Windows registry hive directly without your BitLocker recovery key. Dualtooth provides a 1-click [🔌 USB] export feature that writes the keys and an auto-launching .desktop script directly to any FAT32 USB thumb drive, bypassing BitLocker completely.

What if I want to undo the changes?

Dualtooth creates an automatic timestamped backup of every configuration file before writing. You can run Dualtooth.exe --undo from command line or click Rollback to restore your original state instantly.
