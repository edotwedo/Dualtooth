The Handheld Dual-Boot Pain

When gaming on handhelds, you constantly jump between SteamOS/Bazzite (for native gaming) and Windows 11 (for Game Pass, anti-cheat titles, or Destiny 2 / Call of Duty / Valorant).

  • Xbox & DualSense Controllers: Controllers negotiate a single active link key with the host hardware. Booting between SteamOS and Windows breaks connection immediately.
  • AirPods & Wireless Earbuds: BLE audio peripherals reject connection until you unpair and re-pair from scratch on every boot.
  • MicroSD / USB Export: SteamOS's read-only immutable filesystem makes manual Linux configuration tricky.
